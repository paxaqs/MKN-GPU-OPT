# MKN-GPU-OPT — оптимизация ИИ-программы на GPU

Производственная практика (технологическая (проектно-технологическая)), 9 семестр.
Организация: ООО «МОСКОМНЕТ» (ООО «МКН»), г. Москва.
Обучающийся: Аверин Евгений Павлович, группа ОБП-12210МОиибд.

## Задача

Одно из направлений работы ООО «МКН» — строительство и обслуживание систем
видеофиксации на дорогах г. Москвы. Камеры выдают непрерывный поток кадров,
и первый шаг видеоаналитики — отобрать кадры, на которых есть автотранспорт.
Эту задачу решает нейросеть, и от скорости её работы зависит, сколько камер
можно обслужить одним вычислительным сервером.

Цель работы — ускорить программу, которая с помощью нейросети ResNet-50
определяет наличие транспорта на кадре, за счёт эффективного использования
графического процессора (GPU), не ухудшив качество распознавания.

Реальные камеры для эксперимента не нужны: поток кадров имитируется открытым
набором изображений CIFAR-10 (автомобили и грузовики — «транспорт»,
животные — «не транспорт»).

## Что сделано

Оптимизации применяются по одной, каждая поверх предыдущей. После каждого шага
программа замеряет скорость, видеопамять, энергопотребление и качество.

| Вариант | Что меняется |
|---|---|
| V0 | Исходная версия: кадры по одному, предобработка на CPU (PIL), FP32 |
| V1 | Отключено вычисление градиентов (`torch.inference_mode`) |
| V2 | Пакетная обработка — по 64 кадра за раз |
| V3 | Предобработка (масштабирование, нормализация) перенесена на GPU, закреплённая память |
| V4 | Формат памяти `channels_last` и автоподбор алгоритмов свёрток (`cudnn.benchmark`) |
| V5 | Смешанная точность FP16 (использует тензорные ядра GPU) |
| V6 | Компиляция модели `torch.compile` |

Дополнительно программа:
* подбирает оптимальный размер пакета (16–256 кадров);
* профилирует исходную и оптимизированную версии (`torch.profiler`), чтобы найти узкие места;
* проверяет, что результаты совпадают с исходной версией и одинаковы между повторами.

## Как запустить

Самый простой способ — Google Colab (бесплатный GPU):
1. Открыть `notebooks/colab_gpu_benchmark.ipynb` в Colab.
2. Включить GPU: *Среда выполнения → Сменить среду выполнения → GPU*.
3. *Среда выполнения → Выполнить все*.

На компьютере с видеокартой NVIDIA:
```
pip install -r requirements.txt
python -m src.run_all
```

## Структура проекта

* `src/data.py` — подготовка кадров (CIFAR-10)
* `src/model.py` — модель ResNet-50 и список классов транспорта
* `src/pipelines.py` — варианты конвейера V0–V6
* `src/benchmark.py` — замеры скорости, памяти, энергии, качества, стабильности
* `src/profiling.py` — профилирование узких мест
* `src/plots.py` — графики
* `src/run_all.py` — главный скрипт
* `notebooks/colab_gpu_benchmark.ipynb` — ноутбук для Google Colab
* `results/` — результаты замеров (таблицы, графики, профили)
* `.github/workflows/test.yml` — автоматическая проверка кода при каждом обновлении
